## 6. Implementation steps

1. Port generator v1 and playable v2 with the same version labels, ordered inputs/draws, IDs/logical keys, names, attribute/value/wage and contract formulas.
2. Preserve four leagues/72 clubs/3,000 players, owned/free-agent counts, roster coverage, GK/homegrown data, budgets and potential constraints.
3. Port prepareStandaloneCareer and fingerprint data exactly, including chosen club/preset, source IDs, explicit year and injected audit timestamp. No clock/environment-derived inputs.
4. Generate/validate pure DTOs; no SQLite writes or Tauri imports. Existing snapshots import without invoking generation.
5. Compare full normalized expected worlds or the documented canonical digest. Alternate campaign IDs change only references; alternate year changes only defined dates.
6. Retain initialization receipt/allocation/constitution content and exact fingerprint semantics; do not introduce two-club AI transactions or development.

## 7. Tests to add/change

- Exact v1/v2 world and prepared-career parity, including fixed Unicode seed cases.
